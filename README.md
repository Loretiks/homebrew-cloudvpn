# Homebrew tap — Cloud VPN (macOS)

```bash
brew tap Loretiks/cloudvpn https://github.com/Loretiks/homebrew-cloudvpn
brew install --cask cloudvpn
```

Если brew попросит доверить tap: `brew trust loretiks/cloudvpn`.

Установка через brew снимает карантин автоматически — приложение запускается сразу,
без ручного обхода Gatekeeper. Обновляется само через Sparkle.
